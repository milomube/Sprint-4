-- Objetivos generales del sprint
Profundizar en la arquitectura y la optimización de plataformas analíticas en BigQuery, incorporando estrategias de almacenamiento eficiente, control de costes y diseño escalable.
Al mismo tiempo, te vas a sumergir en el uso de SQL analítico avanzado, funciones de ventana y mecanismos de automatización para construir soluciones analíticas robustas, sostenibles y orientadas a negocio.
